# 执行前科学决策卡

将任务先转化为可核查的科学与工程决策，经人工确认后再开展实现。每张卡必须回答下面七项问题，并将回答落实为预计执行方案。

## 执行规则

- 在正式执行任务、运行实验或修改文件前，向用户展示七项决策卡和预计执行方案，必须等待用户明确确认该方案后再执行。确认前仅开展形成方案所必需的只读检查、澄清和方案修订；可以先读取需求、项目规范、相关文件和数据元信息，这些准备性检查不能代替决策卡及人工确认。
- 每个新任务都要填写并提交人工确认。同一任务中，已确认的卡与方案若已覆盖随后代码修改，可以沿用，无须对每个文件或每次工具调用重复填写、确认。若进入未被已确认方案覆盖的代码修改阶段，或目标、数据、假设、约束、验收标准、预计修改与新增范围实质变化，先更新卡与方案，重新获得人工确认后再继续。
- 按当前任务范围作答，不把一次局部修复扩展成完整研究项目。对文档、配置或维护任务，仍保留七项，并将无关内容标为“不适用”及原因。
- 区分“已知（注明来源）”“假设（待验证）”“待确认”“不适用（说明原因）”。不得把计划中的样本量、硬件能力、精度目标或性能假设写成实测事实。
- 能从已有文件和只读检查获得的信息，先自行核查。未知信息若不妨碍形成方案，在卡中写明假设、验证办法及适用范围，一并提交人工确认；若会改变科学结论或实现正确性且无法合理确定，只询问必要信息。正式执行阶段仅在已确认方案范围内推进不依赖该答案的工作。
- 人工确认是正式执行的前置条件，以用户对当前方案明确表示同意为准。用户提出任务本身、沉默、等待超时或没有提出反对意见，均不等于确认。用户要求调整方案时，先修订并再次提交确认。
- 首次展示方案后，保持“待人工确认、尚未开始正式执行”状态；执行中提交变更方案时，暂停相关执行，等待重新确认。在确认前不修改文件、运行实验或在后台启动相应方案的正式执行。默认在当前对话中展示，无须为每次任务另建记录文件。

## 七项必答问题

### 1. 科学目标与任务类型

说明要回答的科学问题、当前任务在其中的作用，以及待检验的假设或预期交付物。判断任务属于回归、分类、排序、生成、聚类、异常检测中的哪一种或哪几种，并说明理由；如属于 PDE 求解、参数反演或工程维护，直接写明，不强行归类。

涉及模型时，明确输入、输出和学习目标，区分预测、拟合、求解与校准。只将本次工作能够验证的内容作为结论目标。

### 2. 一个训练样本是什么，最小实验执行单元是什么

分别定义这两个对象，不把一条记录、一次前向计算、一个 batch 和一次独立实验混为一谈。

- **训练样本**：描述一个样本的输入、目标或约束、来源及标识；说明是否存在监督标签。对于 PINN，区分内部配点、初始条件点、边界条件点和监督数据；PDE 残差约束不等于真实观测标签。
- **最小实验执行单元**：定义能独立运行、复现并产生可评估结果的一次试验，例如固定数据划分、模型配置、物理参数和随机种子的一次训练或求解。说明其包含哪些采样、特征计算、导数计算、拟合与评估步骤；重复试验的单位另行说明。

不涉及训练时，说明训练样本不适用，并给出本次最小可验证的工作单元。

### 3. 数据模态与数据结构

指出数据属于表格、图像、时序、图、序列、谱、场或其组合。说明实际存储结构与科学对象之间的关系，例如表格存储的坐标点对应连续解场，不因文件格式而误判模态。

列出关键字段或张量形状、坐标与单位，以及输入、目标、物理参数之间的对应关系。涉及时间、空间、合约或轨迹关联时，说明关联标识和划分方式，避免相关样本跨训练集与测试集造成泄漏。

### 4. 数据规模、标签、维度、噪声与标注成本

在本次范围内回答：

- **规模 N**：样本计数单位，训练、验证、测试规模及来源；区分已有数量与计划生成数量。按需要分别统计配点、边界点、参数组合、轨迹和独立实验次数。
- **标签**：是否有标签、来源、带标签样本数，以及分类的类别数或回归的目标变量数；无监督或物理约束任务明确哪些样本没有标签。
- **维度**：输入、输出及相关特征维度；区分数据维度、量子状态空间维度与特征数。
- **噪声**：观测噪声、数值误差、仿真误差或测量噪声的来源及处理方式；尚未评估时明确说明，不能默认无噪声。
- **成本**：标签获取或生成成本，必要时补充采样、仿真、特征缓存的时间与内存预算。不得将昂贵模拟生成的数据视为无成本。

数值未知时注明待确认及获取办法，不捏造具体规模或预算。

### 5. 不可违背的科学先验与约束

列出与本次任务有关的对称性、守恒、单调性、正性、机理方程、初始条件、边界条件、量纲及有效域；不机械地要求所有任务满足全部先验。

对每项关键约束说明：来源和适用条件；它是严格成立的性质、建模假设还是数值近似；计划如何在参数化、求解、损失或验证中体现。区分硬性保证与软惩罚，不能声称加入损失项即已保证满足约束。

本项目涉及 Rydberg-QRC-PINN 时，读取[研究实施方案](../../docs/plan/Rydberg_QRC_PINN_Research_Plan.md)的相关部分，以当前任务和已确认设定为准。尤其核查：

- 金融剩余期限与量子演化时间的含义及单位，PDE 符号、无量纲化、初边值条件和 Greeks 的尺度转换。
- D0 配点与 D1 解析参考的角色，训练和独立评估的隔离；监督消融需明确单独的实验设定。
- 固定储备池与可训练读出的边界，基线比较的数据、精度和计算预算。
- 截断边界与缩减 Hilbert 空间等近似的适用条件；20 原子运行能力、CUDA 支持和量子优势需实际验证，不能作为已证实结论。

研究计划中的“建议”“示例”“待核实”保留其原有状态。若拟修改既有科学设定，应先在卡中说明变更理由与验证办法。

### 6. 答案应当长什么样

定义交付物、精度和验收方式，而不只写“提高效果”。按相关性说明：

- **精度**：评价指标、基线、评估数据与区域、容差及来源；阈值未确定时注明待确认或提出带理由的候选值。
- **解释**：需要解释的变量、物理意义、误差来源或可追溯信息。
- **不确定性**：是否需要重复试验、区间或稳定性分析；说明所反映的随机性，不将种子间波动等同于全部预测不确定性。
- **内插/外推**：训练覆盖域与测试域，是否含未见参数、时间或空间区域；结论不得超出验证范围。

文档、配置或维护任务按实际交付物给出可检查的完成标准，不虚构模型精度。

### 7. 预计修改和新增的范围

列明本次计划修改和新增的对象及其目的，按相关性说明：

- **文件与模块**：预计修改或新增的文件路径、模块，以及相关测试、文档或配置。
- **函数与类**：预计调整或新增的函数、类或方法及其职责；涉及现有对象时，先核查其实际位置。
- **API 与接口**：预计修改或新增的 API、调用接口或数据接口；说明输入输出、签名或行为变化及兼容性影响。

精确路径或名称尚未确定时，写明候选范围和定位办法，不编造已有对象。不涉及代码修改时，明确说明，并列出实际涉及的文档、配置或其他交付物。执行中范围发生实质变化时，先更新本项与预计方案，重新获得人工确认后再继续。

## 对用户的输出模板

保持七项顺序，每项写与本次任务相关的具体回答；简单任务可每项一句。模板中的提示需替换为实际内容。

```text
执行前决策卡
1. 科学目标与任务类型：科学问题 / 本次目标；任务类型；输入与输出。
2. 样本与最小实验单元：一个样本的定义及标签性质；一次可独立验证的试验或工作单元。
3. 数据模态与结构：模态、字段或形状、单位及数据关联。
4. 规模与成本：N、标签数量、维度、噪声、标注或生成成本；未知项与核查办法。
5. 科学先验与约束：必须遵守的条件、假设或近似；实现和验证方式。
6. 输出与验收：交付物、精度、解释、不确定性、内插/外推范围；不适用项说明原因。
7. 预计修改和新增的范围：文件或模块、函数或类、API 或数据接口及其变更目的；接口变化与兼容性影响。

预计执行方案：基于上述决策，列出本次步骤、修改范围、验证方式及完成条件。

方案状态：待人工确认；正式执行状态：尚未开始（变更方案时填写“已暂停，待重新确认”）。
请确认是否按上述方案执行；如需调整，请指出。
```

执行中若证据推翻卡中的假设，先修订相关决策与方案，重新获得人工确认后再继续。最终报告区分已完成、已验证和仍未验证的内容，不把预计结果当成实际结果。
